not re-derived every session. CLAUDE.md routes here.

- Exercise-database taxonomy / categorization rules.
- Progression-logic rules (how RPE → next-week changes).
- Gotchas and dead-ends already ruled out (save future re-investigation).

## What does NOT belong here
- Anything the code or git history already records.
- Per-conversation scratch.
